# API 网关路由歧义排查工具

粘贴多条路由规则（静态段、`:param` 单段参数、`*` 零或多段通配、优先级数字），
系统自动找出可能同时命中的规则对，生成最短具体请求路径作为冲突见证，
并按「优先级数字越大越先、平手按输入顺序」模拟最终命中。
支持勾选禁用单条规则即时重算，并可导出包含冲突对、见证路径与胜出规则的 JSON。

## 变更影响模式

切换到「变更影响」标签后，当前规则自动作为基线，可再粘贴一份候选规则与请求样本
（每行 `[次数] 路径`，次数省略时为 1，`#` 开头为注释），系统用同一套匹配语义
逐条计算两套规则下的胜出规则（规范化模式与优先级均相同才视为同一规则），按
「命中迁移、新增命中、变为未命中、无变化」分类并汇总受影响请求次数。
非法样本逐行提示且不参与统计；页面支持按分类筛选、查看基线/候选胜出规则与次数，
并可导出本次影响明细 JSON。规则或样本变化时自动防抖重算。

## 启动

```bash
docker compose up --build
```

## 访问

- 地址：http://localhost:8080 （端口 `8080`）

## 配置

- `PORT`：服务监听端口，默认 `8080`；修改后需同步调整 `docker-compose.yml` 的端口映射。

技术栈：TypeScript + React（Vite）前端、Express 后端；镜像由根目录 `Dockerfile` 多阶段构建，依赖安装与初始化均在容器构建/启动时完成。
